# Seaborn Data Visualization Assignment

This assignment explores statistical data visualization and complex charting techniques using the `seaborn` library.

## Files Overview

### `seaborn_task1.py` - Relational Plots
- **Scatter Plots:** Uses `sns.relplot()` to visualize relationships between age, final grade, and sex.

### `seaborn_task2.py` - Line Plots
- **Trends:** Uses `sns.lineplot()` to show continuous trends (Age vs Final Grade).

### `seaborn_task3.py` - Distributions
- **Histograms & KDE:** Demonstrates `sns.histplot()` and `sns.kdeplot()` to show the distribution of student absences.

### `seaborn_task4.py` - Bivariate Distributions
- **Complex Histograms:** Creates a bivariate histogram mapping absences against final grades.

### `seaborn_task5.py` - Pair Plots
- **Multivariate Analysis:** Uses `sns.pairplot()` to instantly visualize pairwise relationships across multiple numeric columns.

### `seaborn_task6.py` - Bar Plots
- **Categorical Data:** Uses `sns.barplot()` to show the average final grade segmented by school.

### `seaborn_task7.py` - Regression Plots
- **Linear Models:** Uses `sns.regplot()` and `sns.lmplot()` to plot data points along with a linear regression line.

### `seaborn_task8.py` - Facet Grids
- **Grid Layouts:** Uses `sns.FacetGrid()` to create multiple subplots based on categorical variables (e.g., sex).

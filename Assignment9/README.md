# NumPy Numerical Processing Assignment

This assignment focuses on high-performance numerical computing and array manipulations using the `numpy` library.

## Files Overview

### `numpy_task1.py` - Array Creation
- **Initialization:** Demonstrates creating 1D and 2D numpy arrays from Python lists.

### `numpy_task2.py` - Array Attributes
- **Metadata:** Inspects array properties like `.shape`, `.ndim`, and `.dtype`.

### `numpy_task3.py` - Indexing and Slicing
- **Data Access:** Extracts specific elements, rows, or columns from multidimensional arrays.

### `numpy_task4.py` - Vectorized Operations
- **Math Operations:** Performs element-wise addition, multiplication, and scalar operations without explicit loops.

### `numpy_task5.py` - Statistical Methods
- **Statistics:** Calculates mean, median, standard deviation, and sum across different array axes.

### `numpy_task6.py` - Reshaping Arrays
- **Transformation:** Uses `.reshape()` to change array dimensions for matrix operations.

### `numpy_task7.py` - Boolean Indexing
- **Filtering:** Applies condition-based filtering to extract elements meeting specific criteria (e.g., values above the mean).

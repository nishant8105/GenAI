# Pandas Data Manipulation Assignment

This assignment covers data analysis and manipulation using Series and DataFrames from the `pandas` library.

## Files Overview

### `pandas_task1.py` - Pandas Series
- **Series Creation:** Creates a Series from a list of marks, demonstrating index and values.

### `pandas_task2.py` - Series Operations
- **Vectorization:** Performs mathematical operations (addition, subtraction, multiplication) on an entire Series.

### `pandas_task3.py` - Series Aggregation
- **Aggregation:** Calculates min, max, sum, and mean. Uses `.apply()` with a lambda function for conditional logic.

### `pandas_task4.py` - DataFrame Creation
- **DataFrames:** Constructs a DataFrame from a dictionary of student data. Uses `.head()` and `.tail()`.

### `pandas_task5.py` - DataFrame Inspection
- **Exploration:** Uses `.info()` and `.describe()` to analyze DataFrame structures and statistics. Uses `.sort_values()`.

### `pandas_task6.py` - Conditional Filtering
- **Data Extraction:** Filters students based on marks and subjects using boolean indexing.

### `pandas_task7.py` - GroupBy Operations
- **Grouping:** Uses `.groupby()` to calculate average and maximum marks grouped by subject.

### `pandas_task8.py` - Pandas Plotting
- **Visualization:** Integrates with Matplotlib to plot bar charts, line plots, and histograms directly from the DataFrame.

### `pandas_task9.py` - Real-world Data Processing
- **Sales Data:** Analyzes a sales DataFrame to find total revenue, average revenue, and the best performing days.

# Python Regular Expressions and Pattern Matching Assignment

This assignment explores text processing and pattern matching using Python's `re` module.

## Files Overview

### `task1.py` - Basic Matching
- **Pattern Search:** Introduces simple regex matching to find specific words or sequences in a string.

### `task2.py` - Character Classes
- **Data Extraction:** Uses character classes to extract numeric values (digits) or specific character sets from text.

### `task3.py` - Quantifiers
- **Greedy/Lazy matching:** Demonstrates matching patterns that occur one or more times, or optionally, using quantifiers.

### `task4.py` - Anchors and Boundaries
- **String Boundaries:** Validates if a string starts or ends with specific patterns using `^` and `$`.

### `task5.py` - Grouping and Capturing
- **Capturing Groups:** Extracts structured data (like dates or domain names) using parentheses to capture groups.

### `task6.py` - Substitution
- **Regex Replace:** Uses `re.sub()` to clean or censor specific words within a larger text block.

### `task7.py` - Complex Validation
- **Form Validation:** Combines various regex elements to validate complex real-world data like email addresses or phone numbers.

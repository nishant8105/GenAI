# Streamlit Web Applications Assignment

This assignment introduces building interactive web applications and dashboards using the `streamlit` library.

## Files Overview

### `app_basic.py` - Basic Streamlit App
- **UI Elements:** Demonstrates rendering basic text, headers, and simple interactive widgets using Streamlit.

### `app_dashboard.py` - Data Dashboard
- **Data Visualization:** Loads a dataset and creates an interactive dashboard with dynamic charts and data filters.

### `app_discount.py` - Interactive Calculator
- **Logic Integration:** Creates a functional calculator app where users can input prices and discount rates to instantly see final amounts.

### `app_product_form.py` - Forms and State
- **User Input:** Demonstrates how to handle user data entry securely using `st.form` and manage session states for product catalogs.
